# dsh-chonky-fps

大肥鱼专属帧率模式 · Chonky frame-rate mode

四档帧率，选中即锁定：普通潜水中 60Hz、软乎乎档 90Hz、泡泡快跑档 120Hz、满速甩尾档 144Hz。

> 此帧率模式仅用于 DSH。

## 它做什么

- 在 DSH 网页版 **设置**里新增「大肥鱼专属帧率模式」一页，四档单选。
- 在 dsh-go 手机 App 里提供原生面板（插件页、全部功能、对话详情、输入框「+」），档位与网页共用一份值。
- 选中的档位会锁定：预览轨迹按该档的帧间隔推进，切回标签页会重新确认；档位同时写到 `data-frame-mode` 和 CSS 变量 `--dsh-frame-hz`，页面可据此统一刷新节奏。
- 实测屏幕刷新率，并显示锁定状态：够得到显示「已锁定 ≥120Hz（实测 121Hz）」，够不到显示「未锁定：屏幕最高约 60Hz，跑不到 120Hz」。

## 它不做什么

**它提不了你的真实帧率。** 插件改变不了硬件和浏览器的真实上限。屏幕是 60Hz 时，选 144Hz 档并不会让屏幕跑到 144 帧：页面会如实显示「未锁定：屏幕最高约 60Hz，跑不到 144Hz」，而不是假装成功。**这条提示是正确行为，不是故障**；在 60Hz 屏上指望 144 帧才是误解。

它也不会提高游戏或视频的帧率——它只作用于 DSH 自己的界面。

帧率与 token 无关：调高或调低都不会增加或减少 token，插件全程不调用模型。

## 安装

```sh
dsh plugin --profile web add dsh-chonky-fps
```

或从插件市场安装。

> **装完一定要重启引擎。** `dsh plugin add` 只把插件行写进 profile，不会重新加载它。不重启时，引擎启动可能报 `patch: entry "<id>" not found`，手机端面板也会显示「插件已停用或找不到」。请在 App 的「引擎」页点重启（或重启 `dsh web`），然后刷新网页；手机端再到 **设置 → 插件** 里启用。

重启后仍看不到档位，就再重启一次——安装后的第一次启动才是真正加载新插件的那次。

## 档位

| 档位 | 帧率 | 包内 id |
|---|---|---|
| 普通潜水中 | 60Hz | `dsh-chonky-fps-60` |
| 软乎乎档 | 90Hz | `dsh-chonky-fps-90` |
| 泡泡快跑档 | 120Hz | `dsh-chonky-fps-120` |
| 满速甩尾档 | 144Hz | `dsh-chonky-fps-144` |

状态文件：`~/.dsh/chonky-fps.json`。删除该文件即回到 60Hz 默认档。
